# 🌱 Trader-growing · 交易者成长花园

> **把你的交易人生变成一座花园。** 每天 5 分钟浇水（修行打卡），每周收一篮果实（因子实验），每季度修剪一次（策略体检）——用游戏化守护纪律，用真实市场检验成长。

Trader-growing 是一个**把交易者修行游戏化的本地工具**：用 RPG 式的等级 / 经验值 / 连击 / 徽章系统，追踪交易者的四大核心能力（数学 / 金融 / 心理 / 哲学），并最终与真实世界的投资（黄金、原油、沪深 300ETF、纳指 100ETF）结合。

> ⚠️ **免责声明**：本项目仅供教育与研究，不构成投资建议。历史表现不代表未来收益，任何策略都可能亏损。

## 🎮 核心设计

### 成长花园隐喻（Growing 双关）

| 游戏阶段 | 花园隐喻 | 交易者阶段 |
|---------|---------|-----------|
| 🌱 种子 | 投资想法 | 提出假设 |
| 🌿 发芽 | 回测验证 | spec → 回测 |
| 🌳 小树 | 模拟盘 | 执行交易 |
| 🌲 大树 | 小实盘 | 监控迭代 |
| 🍎 果实 | 因子研究 | 持续收获 |
| ✂️ 修剪 | 策略迭代 | 砍掉过拟合 |

### 四维属性（RPG 角色面板）

- 📐 **数学**：是否理性评估概率与赔率
- 💰 **金融**：是否遵守规则与风控
- 🧠 **心理**：是否控制情绪与冲动
- 🔮 **哲学**：是否接纳不确定与失败

### 游戏化机制

- **XP / 等级**：菜鸟 → 学徒 → 熟练 → 专家 → 大师
- **连击奖励**：连续打卡 ≥3 天，XP ×1.5
- **温和惩罚**：有纪律偏差的日子 XP 减半（不归零，失败也是经验）
- **成就徽章**：零冲动 / 割肉勇士 / 空仓大师 / 四维开花……
- **每日 5 分钟上限**：不是让你沉迷，是让你坚持

## 🚀 快速开始

```bash
# 1. 克隆
git clone https://github.com/<你的用户名>/Trader-growing.git
cd Trader-growing

# 2. 安装依赖
pip install -r requirements.txt

# 3. 看全流程演示（无需任何配置）
python scripts/demo.py

# 4. 每日流程
python scripts/daily_flow.py check    # 打卡（输入四维分数）
python scripts/daily_flow.py status   # 查看角色与花园
python scripts/daily_flow.py plan     # 查看今日策略计划
```
