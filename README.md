## 🌟 这是什么？

**Trader-growing** 是一个把"交易者修行"游戏化的本地工具。

你大概也经历过：明知道要止损，手却停在半空；明知道该空仓，还是忍不住加了一手。然后懊恼、自责、再犯。**问题不在知识，在于纪律没有反馈**——而游戏，是给反馈最强的机器。

我们把交易心性拆成 RPG 的四维属性，用等级、经验值、连击、徽章给你即时反馈：

```
📐 数学 —— 你理性评估概率与赔率了吗？
💰 金融 —— 你遵守规则与风控了吗？
🧠 心理 —— 你控制住情绪与冲动了吗？
🔮 哲学 —— 你接纳不确定与失败了吗？
```

> 🎮 **不是赌场式游戏化**（抽卡/排行榜/焦虑），而是**修行式游戏化**：
> 亏损不被惩罚，被重新框架为经验值；每日 5 分钟上限，超时系统会说——"今天的修行够了，去生活吧"。

## 🏡 成长花园（Growing 的双关）

"Growing"既是**成长**（等级提升），也是**种植**（培育花园）。你的花园里有四棵植物，对应四个维度，每天浇水（打卡）它们才会长大：

```
  Trader-growing · 成长花园
  ========================================
  -@| 数学       [ 65/100]  小树
  -@@ 金融       [ 78/100]  大树
  --| 心理       [ 52/100]  幼苗
  -@| 哲学       [ 70/100]  小树
  ========================================
  提示：每天浇水（打卡），四维才会开花
```

| 游戏阶段 | 花园 | 交易者阶段 |
|---------|------|-----------|
| 🌱 种子 | 投资想法 | 提出假设 |
| 🌿 发芽 | 回测验证 | spec → 回测 |
| 🌳 小树 | 模拟盘 | 执行交易 |
| 🌲 大树 | 小实盘 | 监控迭代 |
| 🍎 果实 | 因子研究 | 持续收获 |
| ✂️ 修剪 | 策略迭代 | 砍掉过拟合的枝条 |

## 🎮 游戏机制

| 机制 | 规则 | 哲学 |
|------|------|------|
| **XP / 等级** | 菜鸟 → 学徒 → 熟练 → 专家 → 大师 | 成长看得见 |
| **连击奖励** | 连续打卡 ≥3 天，XP ×1.5 | 坚持有回报 |
| **温和惩罚** | 有纪律偏差的日子 XP 减半（不归零） | 失败也是经验 |
| **成就徽章** | 零冲动 / 割肉勇士 / 空仓大师 / 四维开花…… | 把"认错"也变成荣誉 |
| **每日 5 分钟** | 超时提醒"今天的修行够了" | 节制是最高级的自律 |

已内置 7 枚初始徽章，例如：

- 🏅 **割肉勇士**：严格执行止损 10 次——把最难的"认错"变成值得炫耀的成就
- 🏅 **空仓大师**：遵守"空仓也是持仓"哲学 30 天——什么都不做，也是一种修为
- 🏅 **四维开花**：四个维度同时 ≥ 70——不允许偏科

## 🚀 快速开始

```bash
# 1. 克隆并进入
git clone https://github.com/Justinjchen-Cornell/Trader-growing.git
cd Trader-growing

# 2. 安装依赖
pip install -r requirements.txt

# 3. 跑全流程演示（3 天模拟：打卡 → 对账 → 成长）
python scripts/demo.py

# 4. 开始你的修行
python scripts/daily_flow.py check    # 每日打卡（输入四维分数）
python scripts/daily_flow.py status   # 查看角色与花园
python scripts/daily_flow.py plan     # 查看今日策略计划
```

Demo 输出示例（有纪律偏差的那一天）：

```
【2026-08-08】打卡 +5 XP | 连击 2 | 偏差 4 条
    🔴 计划外交易：策略建议「持有不动」，但今天发生了交易
    🔴 冲动交易：有计划外开仓/加仓（违反数学维度纪律）
    🔴 手动移动止损线（违反金融维度纪律）
    🔴 交易未严格按计划执行
```
