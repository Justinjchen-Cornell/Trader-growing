# 🌱 Trader-growing · 修行日历（每日 5 分钟版）

> 打印贴桌。**节奏比努力重要**——量化不是靠加班赚钱，而是靠让研究流程持续运转。

---

## ☀️ 每日（5 分钟）

### 盘前（2 分钟）——看天气

```bash
python scripts/update_data.py        # ① 更新数据（数据旧了才需要）
python scripts/tg.py dashboard       # ② 四资产"天气"：趋势 / 动量 / 波动
python scripts/tg.py plan            # ③ 今日策略计划（若已生成）
```

三问：市场是什么状态？我的仓位和它匹配吗？今天有没有该做不该做的事？

### 盘后（3 分钟）——浇水 + 对账

```bash
python scripts/tg.py check           # ④ 四维打分（参考打分标准）
python scripts/tg.py reconcile       # ⑤ 纪律对账（计划 vs 实际）
```

三问：今天有红牌吗？如果有，错在哪一维？明天怎么补？

> 💡 没有交易的日子，`check` 就审视"如果今天有信号，我会不会手抖"；`reconcile` 自然显示无偏差。
> **修行不依赖交易，交易依赖修行。**

---

## 📅 每周（30 分钟）——一个实验

```bash
python scripts/tg.py quest-done factor    # 完成因子实验任务（+30 XP）
```

第 9 章流程四步：① 提假设 → ② 算 IC → ③ 分组分析 → ④ 记录结论。

备选任务：`quest-done param`（参数研究）/ `quest-done backtest`（回测复现）。

---

## 🗓️ 每月（半天）——复盘

- 跑 `tg.py stats`：纪律分 vs 红牌的相关性——**用数据证明修行有没有用**
- 翻 Web 界面"📊 成长"tab：曲线趋势
- 问三个问题：① 假设确认率多少？② 哪些被推翻、为什么？③ 下月研究什么？

---

## 🌳 每季度（1-2 天）——修剪

- 策略完整体检（第 5/6 章工具）：基准对比 / 逐年拆解 / 参数敏感性 / 样本外
- 问：这个策略还值得持有吗？我的纪律配不配下一个层级？

---

## 📖 四维打分参考标准（避免拍脑袋）

| 分数 | 📐 数学 | 💰 金融 | 🧠 心理 | 🔮 哲学 |
|------|---------|---------|---------|---------|
| **90+** | 每笔交易都能说出胜率/赔率 | 止损/仓位/成本全部事前锁定 | 全天零情绪波动 | 坦然接受任何结果 |
| **70-89** | 多数交易有依据 | 偶有微调但没越界 | 冲动前能停 10 秒 | 接受亏损是成本 |
| **50-69** | 凭感觉+少量依据 | 有时"这次例外" | 事后才后悔 | 嘴上接受心里抗拒 |
| **30-49** | 纯凭感觉 | 移动过止损/加过仓 | 盘中反复看盘 | 怪市场/怪消息 |
| **<30** | 不知道在赌什么 | 爆过仓/扛过单 | 情绪化操作 | 想靠一次翻本 |

> 打分不是审判，是**照镜子**。今天 40 分没关系，明天能到 50 分就是成长。
