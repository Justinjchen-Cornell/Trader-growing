🚀 快速开始 约 3 分钟

# 1. 克隆
git clone https://github.com/Justinjchen-Cornell/Trader-growing.git
cd Trader-growing

# 2. 装依赖
pip install -r requirements.txt

# 3. 拉行情数据（免费，无需注册）
python scripts/update_data.py --source akshare

# 4. 打开 Web 界面
streamlit run app.py

或纯命令行：python scripts/tg.py week 看修行周报，python scripts/tg.py status 看角色。
